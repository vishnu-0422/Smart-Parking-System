# 🔧 Fix "404 Not Found" Error - Step by Step

## The Problem
You're getting "404 Not Found" when trying to access:
- http://localhost/smart-parking-system/frontend/user/entry.html
- http://localhost/smart-parking-system/frontend/admin/login.html

## ✅ Solution Steps

### Step 1: Verify Your Project Location

**Check where your project is:**
- Current location: `C:\Users\Marellavishnuvardhan\Desktop\smart parking system`

**For XAMPP, you have 2 options:**

#### Option A: Move Project to XAMPP (Recommended)
1. Copy entire project folder
2. Paste to: `C:\xampp\htdocs\`
3. **Rename folder** to remove spaces: `smart-parking-system` (use hyphen, not space)

1. Open: `C:\xampp\apache\conf\httpd.conf`
2. Find line: `DocumentRoot "C:/xampp/htdocs"`
3. Change to: `DocumentRoot "C:/Users/Marellavishnuvardhan/Desktop/smart parking system"`
4. Find line: `<Directory "C:/xampp/htdocs">`
5. Change to: `<Directory "C:/Users/Marellavishnuvardhan/Desktop/smart parking system">`
6. Save file
7. Restart Apache in XAMPP Control Panel

### Step 6: Common Issues & Fixes

#### Issue: "Spaces in folder name"
**Fix:** Rename folder to use hyphens:
- `smart parking system` → `smart-parking-system`

#### Issue: "Apache not serving files"
**Fix:** 
- Check Apache is running (green in XAMPP)
- Restart Apache
- Check port 80 is not in use

#### Issue: "Wrong document root"
**Fix:**
- Verify `httpd.conf` DocumentRoot points to correct folder
- Restart Apache after changes
